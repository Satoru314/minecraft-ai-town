# ロードマップ

各段階で「何ができたら次へ進むか」を決めておく。

## 0. 判断モデルの計測 ✅

- llama.cpp + SemIf を入れ、Qwen3.5-4B と Qwen3-0.6B で yes/no と choice の速度を測る
- **次へ:** 1 判断が 2 秒以内に収まる
- 結果（2026-10-25）: Qwen3.5-4B Q4_K_M、読み込み約 53 トークン/秒。キャッシュが効けば 0.2 秒、状況説明込みの初回は約 6 秒。2 秒には届かないが、行動1つが数十秒かかるので実用上は問題ない

## 1. bot が接続して生き延びる ✅

- Mineflayer で接続し、反射（戦闘・食事・防具・夜の避難）を入れる
- events.jsonl と state.json を書き出す
- **次へ:** イージーで 1 ゲーム日（20分）を、反射だけで生き延びる
- 結果（2026-10-25）: 26.1.2 のサーバーでは移動が拒否され続けたため、サーバーを 1.21.4 に下げた。石の道具をそろえ、ゲーム内で1日半以上死なずに過ごせた

## 2. 判断で動く（進行中）

- スキル（木を切る・掘る・クラフト・建てる・耕す）を実装し、decider の choice で次のスキルを選ぶ
- 設計図を数種類（小屋・畑・倉庫・道）用意する
- **次へ:** 放置して、家と畑ができる

## 3. 戦略役をつなぐ

- 夜に strategist を起動し、events と state から plan.json と日記を書かせる
- Web（許可リストのみ）で調べて knowledge/ に攻略メモを残す
- **次へ:** 人間が何も言わなくても、翌日の行動が計画に沿って変わる

## 4. 育てる

- decision イベントの成功／失敗から判断を改善する（プロンプト調整 → 小さい分類器の学習）
- bot を増やして役割分担する
- 人間のプレイヤーがチャットでお願いできるようにする
